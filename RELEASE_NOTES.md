# PETSCII / 64 v0.1.0

The first public release: a Linux music visualiser with PETSCII-inspired character
graphics and the C64's 16-colour palette.

## Included

- Kaleidoscope, stereo diamonds, and a mirrored character spectrum.
- Live system audio capture with PulseAudio / PipeWire-Pulse.
- Quiet-audio sensitivity adaptation in diamonds and spectrum.
- Fullscreen, colour cycling, trails, freeze, and screenshots.
- Info and cursor hide after two seconds of inactivity.
- Built-in demo mode and a redistributable bitmap font fallback.
- Optional support for your own original C64 character ROM.
- Installer with an app-menu entry and `petscii-64` launcher.

## Get started

See the [installation instructions](https://github.com/caderbyshire/petscii-64#install-on-linux).
Linux, Python 3.12+, and a working desktop audio session are required.
Tested on Omarchy / Arch Linux; Windows and macOS audio capture are not implemented.
